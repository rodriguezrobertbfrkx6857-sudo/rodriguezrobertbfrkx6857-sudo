# 公开筛选与隐私边界

本目录来自一个仍然**私有**的工程项目（固定实现版本 `f3fee23588e1963ae9eecd47d8c5e2170ef9dbb7`）。本次仅选取能够说明工程原理的最小材料，**没有将原私有仓库或其 Git 历史改成 public**。

## 公开的文件

- 手工整理的中文项目介绍、结构图、测试分类、贡献边界及已知限制；
- 开源 MIT 许可下的若干原始代码/单测选摘（相对路径可追踪）；
- 合成输入和确定性 fixture 的文本示例；
- 许可证和上游 OpenDot 署名。

## 没有公开的文件

- 私有源码全库及提交历史、内部审查原始日志和 JSON 测试轨迹；
- 本机绝对路径、用户目录、原生 App 数据库、会话文本、授权记录或私人项目资料；
- API token、凭据、模型文件、环境配置、node_modules 与缓存；
- 未人工确认安全的原生 UI 截图、Windows 可执行文件和应用数据；
- 未经独立复核的任何“模型性能提升百分比”或商业能力对标分数。

精选源码的发布前检查覆盖了常见凭据标记、本机绝对路径和邮箱模式。**这不是全仓库漏洞扫描、软件安全认证或对全部代码的隐私保证**。完整私有仓库不对外公开。

## 使用和引用

本页可作为简历的**公开展示页**。目前公开的是选摘而不是可直接安装的产品；引用时不要称为“完整开源可运行代码仓库”。如以后需要单独的 `opendot-enhanced` 公开仓库，可以将本目录作为迁移基础，再决定是否公开更多经过许可证和隐私审查的模块。
