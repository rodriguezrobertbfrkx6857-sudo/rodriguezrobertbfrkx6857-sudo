# 已知限制（冻结工程原型）

1. **非完整公开软件仓库**：这里是公开技术展示和选摘，完整 Electron 应用源码仍为私有，不保证本目录可独立构建/运行。
2. **真实模型本版未验收**：只有确定性 HTTP fixture 的受控框架演示；不能把它称为真实模型的自主工作能力。
3. **规划与路由有限**：模型生成计划、跨任务 Reviewer 的语义正确性与自动模型择优，没有本版完整留出集证据。
4. **后端兼容有限**：协作 Runtime 仍为 pi；模型路由主要绑定本地模型端点；不代表所有模型或任意框架即插即用。
5. **验收只覆盖声明的条件**：文件身份、回执和字面规则不是完整语义事实证明；CSV 验证仅支持简单无引号子集；`check_code` 为封闭 `add(a,b)` 算术解释器。
6. **运行边界**：Node 文件路径检查不能原子排除完整 Windows TOCTOU 风险；没有 OS 级沙箱；不能保证任意外部工具的 exactly-once。
7. **记忆/技能的效果**：四级记忆与版本治理不是完整语义 RAG；Skills 测试与审批不等于已经证明自学习改善实际成功率。
8. **测试范围**：1123 项包含上游测试，2 个 Windows 符号链接条件跳过；6 个 fixture 检查不等于 6 个独立 Agent 成功任务。
9. **发布性质**：完整 Windows x64 构建存在私有交付记录，但未公开发布未经审查的安装包；不是经过生产安全认证或第三方模型基准认证的商业产品。
