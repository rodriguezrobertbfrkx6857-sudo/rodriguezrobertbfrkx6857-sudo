## 框架级合成演示

- 用户提供两份合成材料与人工 DAG，生成两个独立 pi AgentSession。
- 第一 Dot 经文件审批保存产物；第二 Dot 确实读取上游文件引用；控制器保存 `handoff_consumed` 和 SHA-256 回执。
- 有一次审批拒绝，最终无文件效果；另有暂停、关闭重启后新 run 恢复的检查。
- 原生 Electron 应用、SQLite、受控工具路径是真实执行；**模型输出来自 deterministic HTTP fixture**，所以不证明模型推理或开放规划的质量。
